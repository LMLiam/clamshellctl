# Support

## Read the guides

Start with:

- [Installation](docs/installation.md)
- [Usage](docs/usage.md)
- [Troubleshooting](docs/troubleshooting.md)
- [Privilege model](docs/privilege-model.md)

## Ask a question

Use the
[support question form](https://github.com/LMLiam/clamshellctl/issues/new?template=question.yml)
for a usage question. Include the macOS version, installation method, and safe
diagnostic output.

## Report a bug

Use the
[bug report form](https://github.com/LMLiam/clamshellctl/issues/new?template=bug.yml).
Search open and closed issues first. Include concise steps that reproduce the
problem.

## Request a feature

Use the
[feature request form](https://github.com/LMLiam/clamshellctl/issues/new?template=feature.yml).
Describe the user problem, desired result, alternatives, and privilege impact.

## Report a security problem

Follow [SECURITY.md](SECURITY.md). Do not put vulnerability details in a public
issue.

## Scope

You can use the issue tracker for `clamshellctl` on its documented macOS
versions. The maintainer does not provide general macOS, hardware, display,
dock, or battery support. There is no guaranteed response time.
